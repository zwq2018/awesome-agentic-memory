# Contributing

Thanks for helping make this the best map of agentic memory.

## What belongs here

A resource specifically about **memory for LLM agents** — frameworks, papers, benchmarks, articles, talks, courses. Not generic RAG/vector-DB content unless it's directly framed as agent memory.

## How to add something

1. Fork and edit `README.md`.
2. Put the entry in the right section, keeping the existing format (alphabetical or stars-descending where the section already does that).
3. One line per entry. Say what it *is* and what's *distinctive* — no marketing copy.
4. Verify the link works and points at the canonical source (GitHub repo, arXiv abstract page, official docs).
5. Open a PR with a one-line reason.

## Bar for inclusion

- **Real and locatable** — working URL, not a vague mention.
- **Specific to agent memory** — episodic/semantic/procedural memory, memory lifecycle, long-term recall, temporal/conflict handling.
- **Not a duplicate** — check it isn't already listed under another name (many projects rename, e.g. MemGPT → Letta, MemoryScope → ReMe).

For project entries, include where known: stars (order-of-magnitude is fine), approach, language, license.

Removing or flagging stale/abandoned projects is also a welcome contribution.
